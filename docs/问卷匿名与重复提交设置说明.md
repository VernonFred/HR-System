# 问卷匿名设置与重复提交说明

> 适用模块：问卷中心、专业测评分发弹窗、候选人/填写者入口页
> 适用对象：HR、管理员、运营人员、实施人员
> 更新日期：2026-07-14

## 1. 为什么需要这份说明

在问卷中心中，“问卷编辑”和“问卷分发”是两个不同层级：

- 问卷编辑：维护题目内容，例如单选题、多选题、文本题、评分规则。
- 问卷分发：生成填写链接，配置入口页字段、匿名收集、重复提交、有效期、页面文案。

使用者容易把这两个层级混在一起。典型问题是：想用“手机号码”或“手机号码+姓名”判断同一人是否重复提交，但在编辑问卷题目时又不想让填写者填写手机号。实际系统不是要求把手机号做成一道问卷题，而是在“分发链接”的入口表单中采集手机号或姓名，用于身份识别和重复提交判断。

因此，这份说明的目标是明确：

- 什么时候需要开启匿名。
- 什么时候必须保留手机号/姓名入口字段。
- “允许重复提交”中的“判断依据”到底在判断什么。
- 如果不采集手机号，系统如何处理，以及不建议怎么配置。

## 2. 核心结论

1. 手机号和姓名不需要放进问卷题目里。
2. 如果重复提交要按“手机号”或“手机号+姓名”判断，就必须在“分发弹窗 - 字段配置”中启用对应入口字段。
3. 如果完全不想收集姓名和手机号，就不能再使用“手机号”或“手机号+姓名”作为可靠判定依据。
4. 匿名模式开启后，系统会自动关闭姓名和手机号字段，并改用浏览器本地匿名设备标识做轻量防重复。
5. 匿名模式的防重复只能限制同一浏览器设备，清除缓存、换浏览器或换设备可能绕过。
6. 只保留“姓名”字段时，可以选择“姓名（弱识别）”，但它不能可靠识别真实个人；重名人员会被视为同一人。

## 3. 三个对象的关系

| 对象 | 系统含义 | 主要配置 |
| --- | --- | --- |
| 问卷 | 题目本身 | 题目、选项、是否评分、评分规则 |
| 分发链接 | 一次对外发放的链接配置 | 有效期、入口字段、匿名、重复提交、页面文案、部门路由 |
| 提交记录 | 某个填写者的一次填写过程 | 入口身份信息、答案、状态、提交时间 |

同一份问卷可以创建多个分发链接。每个链接可以有不同的匿名和重复提交规则。例如，同一份满意度问卷可以同时存在：

- 内部员工匿名链接：不收集姓名手机号，使用同设备防重复。
- 候选人实名链接：收集姓名手机号，每个手机号只允许提交一次。
- 培训反馈链接：收集手机号，允许同一人每周提交一次。

## 4. 匿名设置怎么工作

### 开启匿名收集

操作路径：

```text
问卷中心 -> 选择问卷 -> 分发 -> 基本设置 -> 匿名设置 -> 开启“匿名收集（同设备防重复）”
```

开启后系统会自动执行以下逻辑：

- 不收集姓名和手机号。
- 在字段配置中自动禁用姓名、手机号字段。
- 重复提交设置不再使用“手机号”或“手机号+姓名”。
- 后端保存该链接为匿名模式，并强制不允许同一匿名设备重复完成提交。
- 填写者进入链接时，浏览器会生成并保存一个匿名设备标识。

匿名设备标识保存在填写者浏览器本地，用于判断“这个浏览器是否已经提交过这个链接”。

### 匿名模式的适用场景

适合：

- 员工满意度调查。
- 培训反馈。
- 大范围匿名意见收集。
- 不希望管理员看到个人身份的调查问卷。

不适合：

- 需要按人员追踪历史记录。
- 需要按手机号合并候选人档案。
- 需要强身份校验或严格防刷。
- 需要同一个人匿名重复多次提交。

### 匿名模式的限制

匿名模式是轻量防重复，不是强身份认证。

系统可以拦截：

- 同一个浏览器再次提交同一个匿名链接。

系统无法严格拦截：

- 换手机提交。
- 换浏览器提交。
- 清除浏览器缓存后提交。
- 使用无痕模式或不同设备提交。

## 5. 重复提交设置怎么工作

操作路径：

```text
问卷中心 -> 选择问卷 -> 分发 -> 基本设置 -> 重复提交设置
```

重复提交设置只在非匿名模式下使用姓名/手机号规则。

### 允许同一人重复提交：关闭

含义：

- 同一识别对象只能提交一次。
- 默认按手机号识别同一人。
- 第二次提交时会被系统拦截。
- 如果字段配置里没有手机号，系统拿到的手机号为空，多个填写者可能被误判为同一个“空手机号”对象。

推荐字段配置：

- 手机号：启用，必填。
- 姓名：建议启用，是否必填按业务决定。

### 允许同一人重复提交：开启

含义：

- 同一识别对象可以重复提交。
- “判断依据”用于找出这个人的历史提交记录。
- 系统再根据“提交间隔”和“最多提交次数”决定是否放行。

可选判断依据：

| 判断依据 | 含义 | 适用场景 |
| --- | --- | --- |
| 手机号 | 相同手机号视为同一人 | 手机号唯一，最常用 |
| 手机号+姓名 | 手机号和姓名都相同才视为同一人 | 可能存在共用手机号，或需要更细区分 |
| 姓名（弱识别） | 相同姓名视为同一人 | 只收集姓名、接受重名误判风险的低门槛场景 |

提交间隔：

- 不限制：同一识别对象可以立即再次提交。
- 1小时/1天/1周/自定义：距上次完成提交不足该时间时会被拦截。

最多提交次数：

- 0：不限制次数。
- 大于 0：同一识别对象最多可完成指定次数。

## 6. 关键场景说明

### 场景 A：问卷题目里不想出现手机号，但仍要按手机号防重复

正确做法：

1. 在问卷编辑器中不要添加“手机号”题目。
2. 创建分发链接时，不开启匿名。
3. 在“字段配置”中保留“手机号”字段，并设为必填。
4. 在“重复提交设置”中选择需要的规则。

此时填写者看到的是：

```text
入口页：填写姓名、手机号等基本信息
进入问卷：回答正式题目
```

手机号只是入口身份字段，不是问卷题目，不会占用问卷题目数量，也不需要在问卷编辑器里维护。

### 场景 B：不想收集手机号，也想按手机号判断重复

这种配置在逻辑上不成立。

原因是：系统要按手机号判断同一人，就必须拿到手机号。如果入口表单和问卷题目里都没有手机号，系统没有可靠身份依据。

不建议的配置：

```text
匿名模式：关闭
手机号字段：关闭
允许重复提交：开启
判断依据：手机号
提交间隔或次数上限：已配置
```

这种情况下，系统收到的手机号可能为空。所有没有手机号的提交会被归到同一个空值身份上，可能产生以下问题：

- 第二个填写者被误判为重复提交。
- 提交间隔变成对所有未填手机号的人共同生效。
- 最多提交次数变成对所有未填手机号的人共同累计。
- 系统无法判断到底是不是同一个人。

正确选择：

- 如果需要按人控制重复：保留手机号入口字段；如果选择“手机号+姓名”，再同时保留姓名字段。
- 如果不收集身份但想轻量防重复：开启匿名模式。
- 如果不收集身份且允许任何人多次提交：关闭匿名，取消姓名/手机号字段，同时将提交间隔设为“不限制”、最多提交次数设为 0；但这时系统不会识别同一人。

### 场景 C：只保留姓名字段，第二个人被提示不能重复提交

这是最容易让使用者困惑的场景。

常见配置：

```text
匿名收集：关闭
姓名字段：启用
手机号字段：关闭
允许同一人重复提交：关闭
判断依据：默认手机号
```

实际结果：

- 第一个人填写完成后，系统保存了一条手机号为空的已完成提交。
- 第二个人进入同一链接时，因为也没有手机号，系统仍然拿到空手机号。
- 系统按默认“手机号”规则检查，就会把第二个人也视为同一个空手机号对象。
- 所以第二个人会看到不能重复提交的提示。

这种表现不是系统知道两个人是同一个人，而是系统缺少足够身份字段，只能按空手机号归并，导致误拦截。

如果这个问卷的业务目标只是“很多人都能填，不需要识别同一人”，可以这样配置：

```text
匿名收集：关闭
姓名字段：启用
手机号字段：关闭
允许同一人重复提交：开启
判断依据：姓名（弱识别）
提交间隔：不限制
最多提交次数：0
```

这样可以让不同姓名的填写者继续提交，但要向使用者说明：这是弱识别，不是强身份校验。系统无法可靠判断“张三第二次填写”和“另一个也叫张三的人填写”之间的区别。

如果业务目标是“每个人只能填一次”，就不要只保留姓名，应该至少开启手机号字段并设为必填，或改用匿名同设备防重复。

### 场景 D：完全匿名，且每台设备只允许提交一次

推荐配置：

```text
匿名收集：开启
姓名/手机号字段：系统自动关闭
重复提交：系统使用同设备防重复
```

适合匿名满意度调查和匿名意见收集。

### 场景 E：允许同一手机号每天提交一次

推荐配置：

```text
匿名收集：关闭
手机号字段：启用，必填
允许同一人重复提交：开启
判断依据：手机号
提交间隔：1天
最多提交次数：0
```

结果：

- 同一手机号当天再次提交会被拦截。
- 超过 1 天后可以再次提交。
- 不限制总次数。

### 场景 F：允许同一人最多提交 3 次

推荐配置：

```text
匿名收集：关闭
姓名字段：启用，必填
手机号字段：启用，必填
允许同一人重复提交：开启
判断依据：手机号+姓名
提交间隔：不限制
最多提交次数：3
```

结果：

- 同一手机号+姓名最多完成 3 次提交。
- 第 4 次会被拦截。

## 7. 系统实际校验流程

填写者点击分发链接后，系统按以下步骤处理：

1. 读取分发链接配置，包括匿名、字段、重复提交规则。
2. 展示入口页字段。
3. 填写者点击开始答题时，系统先做一次重复提交检查。
4. 检查通过后创建一条进行中的提交记录。
5. 填写者完成题目并最终提交时，系统会再次检查重复提交规则。
6. 第二次检查通过后，提交记录才会变为已完成。

重复校验只统计已完成提交。进行中但未完成的记录不会作为重复提交依据。

最终提交前再次校验是为了防止填写者多开页面绕过开始前检查。

| 匿名调查，同设备只能一次 | 开启 | 关闭 | 关闭 | 系统自动关闭 | 同设备标识 | 不适用 | 1 次/设备 |
| 实名问卷，每人一次 | 关闭 | 建议开启 | 开启且必填 | 关闭 | 手机号 | 不适用 | 1 次 |

## 9. 常见误解

### 误解 1：手机号必须作为问卷题目出现

不需要。手机号应配置在分发链接的入口字段中，而不是问卷题目中。

### 误解 2：关闭手机号字段后，仍可以按手机号判断重复

不可以。系统没有手机号就无法做手机号级别的身份识别。

### 误解 3：匿名模式也可以选择手机号作为判断依据

不可以。匿名模式不会收集姓名和手机号，系统改用浏览器本地匿名设备标识。

### 误解 4：允许重复提交就是完全不校验

不是。允许重复提交表示同一识别对象可以多次提交，但仍可能受提交间隔和最多提交次数限制。

### 误解 5：只填写姓名就可以判断是不是同一个人

不建议这样理解。“姓名（弱识别）”只能按姓名文本归并，不代表系统知道真实身份。重名人员会被视为同一人；姓名为空时也可能出现归并误判。

### 误解 6：匿名防重复可以百分百防止同一个人重复提交

不能。匿名防重复只能识别同一浏览器设备，不能识别真实个人身份。

## 10. 给使用者的一句话说明

如果你要按手机号或手机号+姓名控制重复提交，请在“分发链接”的字段配置里保留这些身份字段；它们不是问卷题目。只保留姓名时，请选择“姓名（弱识别）”，并接受重名误判风险。如果你不想收集身份信息，就应该使用匿名同设备防重复，或开启重复提交并接受系统不识别同一人的结果。
